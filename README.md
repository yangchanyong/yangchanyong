## Project ARK

**Private Cloud & Internal Developer Platform**

개인 서비스를 직접 개발·배포·운영하면서
Backend, Infrastructure, DevOps, AI-Assisted Engineering을 실전 환경에서 다루기 위한 장기 프로젝트입니다.

```text
Internet
   │
   ▼
Nginx / TLS
   │
   ├── Application Services
   │
   └── Internal Services
          │
          └── PostgreSQL

GitLab Self-Managed
   │
   └── GitLab Runner
          │
          └── CI/CD
```

현재 ARK에서는 다음 영역을 직접 구축하고 운영하고 있습니다.

`Ubuntu Server` `Docker` `Nginx` `PostgreSQL`
`GitLab Self-Managed` `GitLab Runner` `CI/CD`
`Spring Boot` `Automation`

또한 **AEGIS**를 통해 AI Agent가 기존 코드와 Architecture를 이해하고
일관된 기준으로 작업할 수 있도록 Coding Rules, Context, Guardrails를 체계화하고 있습니다.
